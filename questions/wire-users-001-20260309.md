# Question — wire-users-001 [RÉSOLU]

**Module** : Users (Auth)
**Bloquant** : Non (résolu par analogie avec wire-medical-001)

## Contexte

La tâche wire-users-001 demande de supprimer les handlers MSW de `users.ts` et de lancer les tests Playwright contre le vrai backend.

## Problème

Les tests Playwright dans `e2e/users/team.spec.ts` dépendent de données MSW avec des IDs fixes (`u-001`, `u-002`, `u-003`) et d'un mécanisme de mot de passe temporaire généré dynamiquement par le handler. Supprimer le handler MSW rendrait ces tests rouges sans un vrai backend tournant avec des données de seed identiques.

## Décision appliquée

**Option B retenue** — Identique à la décision PO sur wire-medical-001-20260309.md et wire-billing-001-20260309.md.

Les tests Playwright restent sur MSW. Le contrat API est validé par les tests Reqnroll backend. Pas de wire E2E frontend→backend pour le MVP.

La tâche wire-users-001 est annulée. Les handlers MSW de `src/mocks/handlers/users.ts` restent en place.
